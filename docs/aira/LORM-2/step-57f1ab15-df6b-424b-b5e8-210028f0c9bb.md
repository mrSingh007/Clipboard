# Product Specification: Theme Switch Button

## Problem & Intended Outcome

**Problem:** The app currently follows the operating system's theme setting (light/dark) automatically and users cannot override it. Users who prefer a different theme than their OS setting have no way to change it.

**Outcome:** Add a theme selection control in Settings that lets users choose between:
- **Light** — Always use light appearance
- **Dark** — Always use dark appearance  
- **System** (default) — Follow the OS theme setting (current behavior)

The chosen theme persists across app restarts.

---

## What Changes & Where Users Notice It

### New UI Element
- **Location:** Settings panel → new "Appearance" section (added as the first section, above existing "General" section)
- **Control:** A segmented control with three options: Light, Dark, System
- **Label:** "Theme" with the three choices, each with a small icon (sun / moon / computer)

### Affected Screens
1. **Settings Panel** — New theme selector appears at the top of settings in the Appearance section
2. **Entire App** — All UI (toolbar, list, settings panel, footer, empty/loading states) updates immediately when theme changes

### User Actions
- Open Settings (gear icon in toolbar or ⌘S)
- Select desired theme option from the segmented control
- Change applies instantly; Settings panel can stay open
- Close Settings — preference is saved automatically

---

## Before vs. After Experience

| Aspect | Before | After |
|--------|--------|-------|
| Theme control | None — locked to OS setting | Three-choice segmented control in Settings |
| Default behavior | Follows OS theme | Follows OS theme ("System" option selected) |
| Persistence | N/A | User's choice saved & restored on restart |
| Immediate effect | N/A | Yes — app re-renders in new theme instantly |

---

## Included in Scope
- Theme selector UI in Settings panel (segmented control with three options: Light / Dark / System, each with icon)
- Immediate visual update when selection changes
- Persistence of user choice across app launches
- "System" option selected by default (preserves current behavior)
- Works with existing reduced-motion and high-contrast accessibility preferences

## Excluded from Scope
- Custom color themes / accent colors beyond light/dark
- Per-window theme settings (single app-wide setting)
- Automatic time-based switching (e.g., sunset/sunrise)
- Theme sync across multiple devices
- Command-line or shortcut-based theme toggle

---

## Acceptance Criteria

### Visual & Interaction
1. **Settings panel shows theme selector** — Opening Settings reveals a new "Appearance" section (first section) with "Theme" label and three selectable options in a segmented control with icons (sun/moon/computer)
2. **Default is "System"** — On first launch (or if no saved preference), "System" is selected
3. **Immediate preview** — Clicking any option updates the entire app's appearance instantly without closing Settings
4. **Persistence** — After restarting the app, the previously selected theme is applied

### Behavior
5. **"Light" option** — Forces light theme regardless of OS setting
6. **"Dark" option** — Forces dark theme regardless of OS setting
7. **"System" option** — Respects OS theme; updates automatically if user changes OS theme while app is running
8. **No flash on load** — App launches directly into the correct theme (no brief wrong-theme flash)

### Accessibility
9. **Keyboard navigable** — Theme selector reachable and operable via Tab/arrow keys
10. **Screen reader labels** — Each option has clear accessible name ("Light", "Dark", "System (follow OS)")
11. **Respects reduced motion** — Theme transition honors `prefers-reduced-motion`

---

## Resolved Decisions

1. **Control style**: Segmented control (three connected buttons)
2. **Iconography**: Small icons included — sun (Light), moon (Dark), computer (System)
3. **Section ordering**: "Appearance" is the first section in Settings, above "General"
4. **System option label**: "System" (no dynamic subtitle)
5. **Transition animation**: Instant switch (no animation)
