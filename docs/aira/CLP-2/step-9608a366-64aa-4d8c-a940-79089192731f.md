# Ticket: CLP‑2 – Dark & Light Theme Toggle

## Plan

- **Why we need it**: Some users prefer a dark look to reduce eye strain or save battery, while others like a bright (white) look. Giving a switch lets each person choose what feels best.

- **Where the switch will live**: We will put a small button in the top toolbar where the other icons already are. It will show a simple sun/moon icon and have an accessible label like “Toggle light / dark theme”.

- **How the switch works**: When a user clicks the button, the whole app will instantly change its colours from light to dark or back. The change will be applied by adding or removing a class on the main page, which tells the style sheet which set of colours to use.

- **Remembering the choice**: The app will remember the last theme the user picked. That setting will be saved locally, so the next time the program starts it will open with the same theme the user chose before.

- **Default behaviour**: If the user has never changed the theme, the app will follow the operating system’s setting (light on a light system, dark on a dark system). This keeps the experience familiar for new users.

- **Accessibility**: The button will be reachable by keyboard (Tab navigation) and will have a clear label for screen‑reader users. Colours used in both themes will meet contrast guidelines so text is always easy to read.

- **Design work**: We will add the necessary colour variables for both themes in the style sheet, and create the small sun/moon icon for the button.

- **Testing**: The feature will be tested on macOS and Windows, in both light and dark modes, and with the keyboard and screen‑reader tools to ensure it works for everyone.

- **Documentation**: The help page and any onboarding tips will be updated to mention the new “Toggle Theme” button, explaining how to use it.

- **Release steps**: After development, the change will go through the normal QA process and then be shipped in the next version of the app.
