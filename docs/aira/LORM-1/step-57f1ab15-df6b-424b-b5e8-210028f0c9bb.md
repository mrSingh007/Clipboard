# LORM-1: Dark/Light Theme Toggle — Product Specification

---

## 📋 Executive Summary

**Feature:** Add a single toggle button that lets users switch the app between **Dark Mode** and **Light Mode**.

**Goal:** Give users control over the app's visual appearance so it matches their system preference or personal comfort, reducing eye strain and improving usability in different lighting conditions.

---

## 🎯 User Problem

- Users who prefer dark interfaces (especially at night or in low-light environments) currently cannot change the app's bright default appearance.
- Users on systems set to dark mode see a jarring bright window when they open the clipboard history.
- No way to match the app's look to the operating system's theme setting.

---

## ✅ Proposed Solution

**One toggle button** placed in the app's settings area that:

1. **Switches instantly** between Light and Dark themes
2. **Remembers the user's choice** across app restarts
3. **Defaults to the system preference** on first launch (if the OS is in dark mode, start dark; otherwise light)

---

## 🖥️ Where It Lives

- **Location:** Settings panel (accessible via the gear icon ⚙️ or `Cmd+S` / `Ctrl+S`)
- **Control type:** A single toggle switch labeled "Dark Mode" or "Theme" with two states:
  - ☀️ Light (default when system is light)
  - 🌙 Dark (default when system is dark)

---

## 🔄 User Flow

1. User opens Settings (gear icon or keyboard shortcut)
2. User sees the theme toggle showing the current mode
3. User clicks the toggle → theme switches immediately
4. User closes Settings → preference is saved automatically
5. Next time the app opens, it remembers the last chosen theme

---

## 🎨 Visual Behavior

| Element | Light Mode | Dark Mode |
|---------|------------|-----------|
| Window background | White / very light gray | Dark gray / near-black |
| Text (primary) | Dark gray / black | White / light gray |
| Text (secondary/muted) | Medium gray | Medium-light gray |
| Entry hover highlight | Light blue / gray | Darker blue / gray |
| Pinned entry indicator | Visible contrast | Visible contrast |
| Search input | Light background, dark text | Dark background, light text |
| Borders/dividers | Light gray | Dark gray |
| Scrollbar | System default | System default |

> **Note:** The toggle itself should always be clearly visible in both themes.

---

## 💾 Persistence & Defaults

| Scenario | Behavior |
|----------|----------|
| **First launch** | Detect OS theme → apply matching theme |
| **User toggles** | Save choice to local settings immediately |
| **App restart** | Load saved choice (override OS detection) |
| **Settings reset** | Revert to OS theme detection |

---

## ⌨️ Keyboard Accessibility

- The toggle must be reachable via **Tab** navigation in Settings
- **Space / Enter** activates the toggle when focused
- Screen readers should announce: "Dark mode, switch button, [on/off]"

---

## 📱 Platform Considerations

| Platform | Notes |
|----------|-------|
| **macOS** | Respects system "Auto" appearance if user hasn't set a preference; native vibrancy effects optional |
| **Windows** | Follows Windows 10/11 "Choose your mode" setting for initial default |

---

## ✅ Acceptance Criteria

1. **Toggle exists** in Settings panel
2. **Immediate visual change** when toggled (no restart needed)
3. **Preference persists** after quit/restart
4. **First launch defaults** to OS theme
5. **All UI elements** (history list, search, pins, buttons, scrollbars) adapt correctly
6. **No flashing** or layout shift during theme switch
7. **Keyboard accessible** and screen-reader friendly
8. **Works on both** macOS and Windows builds

---

## 📦 Out of Scope (Future Enhancements)

- Automatic switching based on time of day (sunrise/sunset)
- "Follow system" as a third explicit option alongside Light/Dark
- Custom accent colors
- Per-window theme (if multiple windows are added later)
- Theme sync across devices (no cloud sync in this app)

---

## 📅 Delivery Notes

- This is a **UI-only change** — no database migrations, no clipboard monitoring changes
- Settings storage already exists (`electron-store`); add one boolean key: `theme: 'light' | 'dark'`
- Renderer (HTML/CSS) handles the visual swap via CSS custom properties or class on `<body>`
- No impact on clipboard history, pinning, search, or shortcuts

---

## 🧪 How to Verify (PO Checklist)

- [ ] Open app fresh → matches my OS theme
- [ ] Open Settings → see toggle showing current mode
- [ ] Click toggle → entire window changes instantly
- [ ] Close and reopen app → my choice is remembered
- [ ] Switch OS theme → app *doesn't* auto-switch (my saved choice wins)
- [ ] Tab to toggle in Settings → press Space → theme flips
- [ ] Verify on both macOS and Windows (if available)
